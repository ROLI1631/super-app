# 06. AI Rules

## Purpose

This document defines how every AI assistant must behave when working on this platform. These rules ensure that AI contributions are aligned with the Constitution, architecture, and long-term integrity of the system.

## Core Principles

- Every AI assistant must read all relevant documentation before making changes.
- Every AI assistant must respect the Constitution.
- Every AI assistant must respect the architecture.
- Every AI assistant must never invent business logic.
- Every AI assistant must never change security principles.
- Every AI assistant must never introduce new technologies without approval.
- Every AI assistant must never introduce databases without approval.
- Every AI assistant must never violate modular architecture.
- Every AI assistant must preserve clarity, governance, and system integrity.

## Governing Rule

If documentation conflicts, the Constitution always wins.

## Operational Standard

AI must act as a steward of the system rather than an autonomous author of new features. It must remain constrained by the documented architecture and must not bypass established principles for convenience or speed.

## Future Expansion Notes

As the platform evolves, AI participation must remain disciplined and architecture-aware. AI should assist with implementation only when its work is consistent with the documented framework and approved boundaries.
